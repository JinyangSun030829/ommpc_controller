# Minimum-snap 轨迹绘图与最大值统计

`traj/minisnap_plot.py` 订阅 `/planning/poly_trajectory`，保持原有多项式消息格式不变。
它仅分析规划参考轨迹，不是无人机实测运动数据。无需修改规划器或控制器。

## 使用

```bash
rosrun ommpc_controller minisnap_plot.py
```

运行绘图节点后发送航点；已有轨迹是否能立即收到取决于发布端是否 latch。
默认输出到 `~/uav_logs/`：

- `trajectory_pvaj_curvature.png`：位置、速度、加速度、jerk、三维空间曲率，共五幅子图。
- `trajectory_metrics.json`：全轨迹最大值、对应时间/段号、各轴绝对最大值和统计参数。

不再计算 yaw、姿态或机体系角速度。旧图片 `trajectory_flatness_euler_verify.png` 不会删除；请查看新文件名。
每次有效新消息覆盖上述两个新输出文件。单后台线程负责绘图；新请求替换未开始的旧请求，过期结果不提交。

## 统计定义

速度、加速度、jerk 的主最大值分别是三维向量的欧氏模长最大值，单位为 `m/s`、`m/s²`、`m/s³`。
JSON 另存 X/Y/Z 各分量的绝对最大值。jerk 由位置多项式解析求三阶导数，不使用有限差分。
每段同时保留左右端点，避免漏掉段间导数跳变。段号从 1 开始。

空间曲率为 `κ = ||v × a|| / ||v||³`，单位为 `1/m`，适用于非零速度的正则曲线。
静止点公式未定义，近零速处可能出现巨大曲率和数值敏感性。绘图前默认排除速度低于
`0.3 m/s` 的连续区间，并向前、向后各扩展 `0.15 s`，包含跨轨迹段边界的邻域。
低速区间根据速度多项式的阈值交点识别，不依赖绘图采样是否刚好捕捉到近停顿点。
排除处显示为断线/NaN，不填零、不插值、不跨排除区间连线，也不按曲率大小任意裁掉真实转弯。
曲率最大值及其标记使用相同的清洗区间，避免已排除的尖峰仍通过最大值圆点拉伸纵轴。
清洗仅影响曲率图和曲率统计，不改变 P/V/A/J、轨迹生成或控制输入。
清洗后没有有效区间时曲率最大值是 N/A，JSON 为 null。清洗后的峰值不能解释为完整轨迹的曲率上界，
也不表示原有近停顿/折返的参考轨迹已经修复。

V/A/J 在各段端点及模长平方导数的数值实根处寻找极值；曲率采用驻点方程、速度阈值交点、网格及局部细化。
因此报告并非单纯绘图采样的最大值，但仍是浮点数值估计，尤其曲率不是严格认证上界。
规划器的 Bernstein 保守界与这里的参考轨迹数值极值是不同概念。

## 参数

| ROS 私有参数 | 默认值 | 含义 |
| --- | --- | --- |
| `~trajectory_topic` | `/planning/poly_trajectory` | 多项式轨迹话题 |
| `~sample_dt` | `0.01` | 期望绘图时间步长，秒 |
| `~max_samples` | `200000` | 长轨迹自动降低绘图密度；必须容纳每段两个端点 |
| `~curvature_min_speed` | `0.3` | 曲率清洗速度下限，m/s，必须大于零 |
| `~curvature_guard_time` | `0.15` | 低速区间前后额外排除时间，秒，可设为零 |
| `~output_dir` | `~/uav_logs` | 输出目录 |
| `~dpi` | `200` | 图片分辨率 |

例如：

```bash
rosrun ommpc_controller minisnap_plot.py _curvature_min_speed:=0.3 _curvature_guard_time:=0.15
python3 tests/test_minisnap_plot.py
```

## 离线验证示例

使用 `fly_cir.py setup=0` 的 245 段几何，初始位置 `(0,0,2)`、初始速度/加速度为零，
通过首次重构后、时间压缩改进前的规划器导出消息，得到总时长 `177.508970 s`：

| 指标 | 数值最大值 | 时间（秒） | 段号 |
| --- | --- | --- | --- |
| 速度模长 | 1.686228509 m/s | 172.755219752 | 242 |
| 加速度模长 | 1.945054652 m/s² | 170.826737389 | 239 |
| jerk 模长 | 2.910797312 m/s³ | 172.789123889 | 242 |
| 曲率（速度 ≥ 0.01 m/s） | 4.250720817 1/m | 175.038363972 | 244 |

这是指定初始状态下的离线示例，不是当前无人机的在线读数。实际每条新轨迹的结果由节点输出。
后续时间优化的当前行为及基准见 [稳定悬停及时间优化说明](minisnap_hover_time_update.md)。
15 项离线测试覆盖解析、时间归一化、非网格极值、三维曲率、低速处理、段间 jerk、长轨迹采样预算、绘图及后台输出，
以及非采样点低速事件、跨段邻域清洗、全部排除和不跨缺失区间连线。
